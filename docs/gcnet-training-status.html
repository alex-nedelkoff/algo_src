What We Learned

Composable Track Segments

8 primitives (straight, turn_90, turn_180, slalom, chicane, climb, dive, orbit) chained into diverse circuits. Tier 1: 44% → 79%

Gate Geometry in Observation

Added gate width/height per lookahead gate + arena extent. Checkpoint surgery to expand 28→33 dims. Tier 1: 79% → 93%, crash: 20% → 10%

Longer Segments (4-6 at 55%)

Too aggressive — policy forgot fundamentals while learning hard tracks. Regressed across the board.

Speed Cap (v_max 7.5 → 3.5)

Hypothesis: slow down to learn transitions. Reality: geometry is the bottleneck, not speed. Tier 2 unchanged.

GRU Temporal Context

Added GRU(64) to MoE policy. The MLP can't reason about maneuver sequences. The GRU can. Tier 2: 32% → 58%, crash: 89% → 39%

Key Insight

Tier 1 is a data problem. Tier 2 is an architecture problem. Diverse training tracks solve tier 1. GRU temporal memory solves tier 2. The MLP policy fundamentally cannot plan through multi-maneuver transitions — it reacts to the current gate but doesn't maintain context about the trajectory through a circuit.
